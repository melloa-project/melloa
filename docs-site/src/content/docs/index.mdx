The current path is intentionally concrete: a dedicated Debian server, a private Telegram bot chat,
two hosted OpenAI-compatible model routes, encrypted backups, and a bounded self-change loop that
can propose, commit, push, deploy, and roll back owner-approved changes.

This site is the public front door. It should help you get a working Melli, then use Melli to improve
the system from there.

## What you need

- a dedicated Debian server you can administer with `sudo`;
- a Telegram bot token; setup discovers your numeric owner ID during private pairing;
- a capable hosted model endpoint, model ID, bearer token, and reviewed pricing;
- an economy hosted model endpoint, model ID, bearer token, and reviewed pricing;
- an owner-mounted encrypted backup repository and a restic password kept off the server;
- a GitHub token for this repository when enabling the self-change loop;
- a Codex/OpenAI API key for the bounded planner worker.
